# Files 示例

`FM.NLB` 只读浏览 profile 配置的 NLoader 目录及其子目录，不访问其他卡或上级目录。
OK 打开子目录或查看文件大小；返回键回到上级，在根目录返回则退出。
单页最多 60 个文件，更多文件通过 `Next page` 查看。超过 2000 项或读取部分失败时
显示明确提示，不把部分列表当作完整目录。

程序要求 ABI 4。声明中的机型版本表示允许加载，不能替代对应机型运行验证。

```sh
sh sdk/examples/fm/build.sh build/<新输出目录>
bash sdk/examples/fm/test.sh build/<新测试目录>
```

主机测试覆盖配置根、进入和返回子目录、文件详情、目录上限及旧 ABI 拒绝；
实际菜单显示和原厂目录读取还须单独通过 QEMU 验证。
